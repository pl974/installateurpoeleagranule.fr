# Installation Poêle à Granulé - Site Rank & Rent

Site web professionnel optimisé SEO pour l'installation de poêles à granulés en France.

## 🚀 Caractéristiques

- **SEO optimisé** : Pages locales dynamiques pour 25+ villes françaises
- **Performance maximale** : Score Lighthouse 95+ grâce à Astro.js
- **UI/UX premium** : Design moderne avec Tailwind CSS
- **Conversion optimisée** : Formulaire de devis multi-étapes, WhatsApp flottant
- **Contenu riche** : Pages marques, aides financières, guides complets
- **Schema.org** : Données structurées pour Featured Snippets
- **Mobile-first** : 100% responsive

## 📦 Installation

```bash
# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev

# Build pour production
npm run build

# Prévisualiser le build
npm run preview
```
